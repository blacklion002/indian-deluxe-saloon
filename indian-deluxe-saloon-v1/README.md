# Indian Deluxe Saloon

A single-screen animated old-school Indian saloon with a fixed bottom music player.

## YouTube playlist
Playlist ID: PLcw7Q5zInFfE

The page uses the official YouTube IFrame Player API. The actual audio/video player is kept visually unobtrusive while the custom bottom controls operate it.

## Run locally
Open `index.html` in a browser. For the smoothest local testing, use a simple local server (for example VS Code Live Server).
